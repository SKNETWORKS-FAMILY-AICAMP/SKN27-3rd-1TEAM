# 3. 각각의 해결법 상세

1. 효율 좋은 캐릭터 판단
  - 해당 캐릭터의 전투력이 기대되는 전투력보다 낮은지 높은지를 판단하여 효율을 판단한다.
  - 우선 다양한 캐릭터들의 세부 스탯, 장비 상태, 스타포스,잠재 등급,유니온,아케인포스,어센틱 포스등의 다양한 피처 데이터들을 바탕으로 타겟인 전투력을 학습하도록한다.
  - 이 학습된 모델이 어떤 특정 캐릭터의 피처값이 들어오면 모델이 예상한 전투력값(기대 전투력)을 도출한다.
  - 이 도출된 기대 전투력과 실제 전투력 사이의 비율을 통해서 사전에 정의한 기준과 비교하여 효율성을 판단한다.
  - 즉 다시말해 이 모델은 기대전투력만을 판단하는 회귀 예측 모델임


# 4.여기서 알 수있는 결론
1. 모델은 단순히 기대전투력만을 정확하게 판단할수있기만 하면 된다.
2. 가장 중요한 것은 analytic 에이전트가 효율,병목,스탯 균형 분석,성장상태진단,개선방향제시를 어떻게 제시할수 있는지를 설계해야함ㅁ
3. 결론적으로 ML 모델은 데이터만 충분하면 딱히 크게 난이도가 어렵지않고 설계가 특히 중요하지는 않음
