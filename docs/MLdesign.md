# 머신 러닝 모델 디자인 

---

# 1. 문제상황
ML을 적용하기 위해서는 타겟이 필요하다.

1.우선 보스 격파 가능성 예측은 특정 보스를 격파했는지에 대한 여부를 직접적으로 수집 불가능->
 현실적으로 타겟이 불분명하여 절대 불가능

# 2.해결법
다음과 같은 것을 판단하는데 필요한 계산값을 도출하는 모델을 학습해야함

1. 효율 좋은 캐릭터 여부

→ “잘 키웠는가?”

2. 병목 존재 여부

→ “문제가 있는가?”

# 3. 해결법 상세

1. 효율 좋은 캐릭터 판단에 대하여
  - 해당 캐릭터의 전투력이 기대되는 전투력보다 낮은지 높은지를 판단하여 효율을 판단한다.
  - 우선 다양한 캐릭터들의 세부 스탯, 장비 상태, 스타포스,잠재 등급,유니온,아케인포스,어센틱 포스등의 다양한 피처 데이터들을 바탕으로 타겟인 전투력을 학습하도록한다.
  - 이 학습된 모델이 어떤 특정 캐릭터의 피처값이 들어오면 모델이 예상한 전투력값(기대 전투력)을 도출한다.
  - 이 도출된 기대 전투력과 실제 전투력 사이의 비율을 통해서 사전에 정의한 기준과 비교하여 효율성을 판단한다.
  - 즉 다시말해 이 모델은 기대전투력만을 판단하는 회귀 예측 모델임


# 4.여기서 알 수있는 점
1. 모델은 단순히 기대전투력만을 정확하게 판단할수있기만 하면 된다.
2. 가장 중요한 것은 analytic 에이전트가 효율,병목,스탯 균형 분석,성장상태진단,개선방향제시를 어떻게 제시할수 있는지를 설계해야함
3. 결론적으로 ML 모델은 데이터만 충분하면 딱히 크게 난이도가 어렵지않고 설계가 특히 중요하지는 않음

# 5. 머신러닝 설계
1. 해당 머신러닝 모델은 회귀 예측모델이며 타겟은 전투력임
2. 사용될 모델은 부스팅계열의 xgboost regressor이다.
3. 더 효과적인 하이퍼 파라미터 탐색을 위해서 베이지안 탐색 적용함
4. 모델 평가지표는 SMAPE,MAE,RMSE를 사용함
5. ML모델을 통해서 예측된 전투력은 현재 스펙의 효율 평가, 성능의 병목존재 여부를 판단하는데 베이스라인으로 사용될 것임
6. 피처는 캐릭터 스펙과 관련된 부분을 적용하되 피처 임포턴스를 바탕으로 필요없는 정보를 드롭하거나 파생피처를 생성하여         모델 성능의 높이는데 기여하도록 한다.

# 6.피처 엔지니어링
1차적으로 적용할 피처:캐릭터 직업,최대최소스탯공격력,데미지,보스몬스터데미지,최종데미지,방어율무시,크리티컬확률,크리티컬 데미지,상태이상 내성,스탠스,방어력,이동속도,점프력,스타포스,아케인포스,어센틱포스,STR,DEX,INT,LUK,HP,MP,일반 몬스터 데미지,속성 내성 무시,상태이상 추가 데미지,무기 숙련도,공격력,마력
