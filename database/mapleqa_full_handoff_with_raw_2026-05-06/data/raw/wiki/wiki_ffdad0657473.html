Battle Square

Removed Content / Feature
This article contains information no longer in-game, and are thus historical records of MapleStory.

Battle Square was a hub for players to enter various modes of Player vs. Player (PvP). Upon its initial release, there were several modes:

  • Free for All: A mode where every player has to fend for themselves and defeat as many other players as possible.
  • Team Match: A mode where up to 10 players could participate, and be split into 2 teams. The team with the most points would win.
  • Ice Knight: A mode where up to 10 players could participate. One random player will be transformed into the Ice Knight, while the other 9 players would be tasked with defeating the Ice Knight within 7 minutes; the winner would be determined based on whether or not the Ice Knight is defeated.
  • Capture the Flag: A GMS-original mode where up to 6 players could participate, and be split into Red and Blue teams. Each team will have a flag, and be able to steal the flag of the opposite team; the first team to steal 3 flags will win.

Each mode would grant Battle Points, which could be exchanged for Gallant Emblems. These were used to purchase items from Larson, including the Level 30 Larson's Challenger Set, and were also a material needed to craft the following Equipment Sets:

  • Level 70 Intaglio's Crescent Moon Set
  • Level 70 Halfmoon Set
  • Level 70 Walker Sets:
    • Force Walker Set
    • Arcane Walker Set
    • Wind Walker Set
    • Mist Walker Set
    • Fortune Walker Set
  • Level 130 Intaglio's Rising Sun Set
  • Level 130 Blazing Sun Set
  • Level 130 Bloody Sets:
    • Agares Bloody Set
    • Eligos Bloody Set
    • Ipos Bloody Set
    • Halphas Bloody Set
    • Vepar Bloody Set

Battle Square was temporarily closed and reopened into Grand Battle, which served as a free-for-all that granted Gallant Emblems based on the amount of time spent. During this time, players could purchase the Level 130 Grand Set with Gallant Emblems:

  • Grand Agares Set
  • Grand Eligos Set
  • Grand Ipos Set
  • Grand Helphas Set
  • Grand Vepar Set

Battle Square was eventually closed again, and has been removed from all servers of the game. The Ice Knight was reused for The Ice Knight's Curse Party Quest, which was eventually closed.

ChinaMS had an alternate version of Battle Square, with NPCs and the map based around the Three Kingdoms period of the Eastern Han dynasty.
