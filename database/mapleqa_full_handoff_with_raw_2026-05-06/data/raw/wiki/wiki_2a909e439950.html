Link Skill

From the MapleStory Wiki, a knowledge base about everything MapleStory
Jump to navigation Jump to search

A Link Skill is a special skill that each class has in their Novice Skills list. Unlike regular skills, Link Skills are transferrable within world at Level 70. Since the NEXT / Stargazer[1] Update, transferring limits and fees have been removed, but the following restrictions remain:

  • 1st Job Advancement must be completed.
  • Giving and receiving characters must be on the same server on the same account.
  • Receiving characters cannot have the Link Skills already (eg. Two Kaisers cannot both link Iron Will to the same character or to each other).
  • One character can only have a max of 12 Link Skills, excluding their own.
  • In the case of shared Link Skills like the Explorers, Cygnus Knights and Resistance, using the same class will not raise a link skill past its second or third level (eg. leveling two Heroes, Battle Mages or Wind Archers to 120 will not raise their respective link skills to Level 4 or 6)
  • Transferring, removing, and accessing presets for link skills cannot be used in inside a boss map.

Link Skills have a maximum of two levels (three in GlobalMS). Zero levels up Rhinne's Blessing by completing story quests. In cases of classes like the Explorers, Cygnus Knights, or Resistance, they can reach an even higher level cap when combined with other characters with the same link skill.

  • Level 1 is given when the character is made
  • Level 2 is given when the character is at Level 120
  • Level 3 is given depending on the server:
    • In GlobalMS, this is given when the character is at Level 210
    • In KoreaMS, this is given when a character is at Level 285, and uses a Proof of a Brilliant Hero item on any available link skill
    • In all servers other than KoreaMS and GlobalMS, this is not available
